About

A developer who likes the whole stack — and the data underneath it

I'm a third-year Computer Science student at Iqra University and a Software Developer at Logicose in Karachi. Day to day I work on business systems: REST APIs in ASP.NET Core, Angular front-ends, and the SQL Server databases behind them. My route into software came through data — Python, statistics and machine learning were my first serious tools — and that shapes how I build: I care about the data model as much as the endpoint. Where I'm heading is AI engineering: bringing LLMs, retrieval-augmented generation and agents into real .NET and Python applications. I'm early on that path, and I'd rather show the work than overstate it.
